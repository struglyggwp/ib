# Практика ИБ

Внутренний портал обучения информационной безопасности. Администратор создаёт учётные записи, назначает упражнения и открывает именной отчёт. Сотрудник входит с паролем портала, разбирает учебный пример и получает объяснение. Отчёт показывает начало и завершение упражнения, результат ответа и статус служебного приглашения.

Портал запускается с пустой базой. В каталоге четыре упражнения. Почта подключается через Zimbra. Приглашение содержит название учебного портала и его общий адрес. В базе сохраняются статус упражнения, время и результат ответа. Пароли портала хранятся в виде хешей.

## Запуск в Docker Desktop

Откройте Docker Desktop в режиме Linux containers. В PowerShell выполните `docker version` и убедитесь, что в выводе есть раздел **Server**.

Распакуйте архив репозитория. Откройте в PowerShell папку, в которой рядом лежат `Dockerfile` и `compose.yaml`. Копируйте из блоков только команды.

```powershell
docker build --network=none -t praktika-ib:1.1 .
```

После успешной сборки запустите контейнеры.

```powershell
docker compose up -d --no-build --pull never --wait
```

Создайте администратора. По умолчанию для локальной проверки используется домен `corp.example.test`. Для корпоративного запуска сначала задайте свой домен по инструкции ниже.

```powershell
docker compose exec app python manage.py admin admin@corp.example.test
```

Команда выведет пароль портала. Зайдите по адресу `http://127.0.0.1:8080` с адресом и паролем из команды. В разделе **Сотрудники** создайте первую учётную запись, затем в **Кампаниях** назначьте ей упражнение. Пароль сотрудника показывается при создании записи.

Прежний стенд может занимать порт 8080. В этом случае выполните `docker compose stop` в папке прежней версии и повторите запуск из новой папки. У новой версии свой том SQLite `praktika-ib_practice-data`.

## Перенос образа на сервер без интернета

Соберите образ на компьютере с доступом к Docker Hub и с той же архитектурой, что у целевого сервера. При первой сборке Docker скачает базовый образ Python. Файлы интерфейса и среда приложения входят в образ.

```powershell
docker save -o praktika-ib-1.1.tar praktika-ib:1.1
```

Перенесите архив образа и `compose.yaml`. Для почты также перенесите `mail.compose.yaml` и подготовьте локальную конфигурацию по инструкции.

```powershell
docker load -i praktika-ib-1.1.tar
docker compose up -d --no-build --pull never --wait
```

Остановка командой `docker compose stop` сохраняет отчёты. Повторный запуск команды создания администратора задаёт новый пароль и завершает его старые сессии.
