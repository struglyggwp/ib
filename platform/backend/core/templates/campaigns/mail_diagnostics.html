Тестовый почтовый ящик

При запуске дополнительного профиля Docker Mailpit перехватывает письма без доставки во внешнюю почту.

Открыть Mailpit (8025)

Mailpit не является Zimbra. Для тестирования настоящей Zimbra укажите её SMTP-хост в .env.
