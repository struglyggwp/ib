# Сетевая модель и интеграции

Compose публикует только `127.0.0.1:8080`. DB и Redis доступны только во внутренней Docker-сети.
Для серверной установки на отдельной VM:
- ограничить входящие соединения firewall: только администраторские рабочие места к HTTPS reverse proxy;
- запретить исходящий интернет на гипервизоре/сетевом firewall;
- разрешить только конкретные внутренние адреса и порты DNS/SMTP/AD, если интеграции включены;
- не полагаться на Docker bridge как на границу безопасности;
- использовать корпоративный DNS и отдельную делегированную учебную зону;
- использовать SMTP submission с TLS, allowlist получателей и sender identity;
- AD подключать read-only service account и ограничить base DN;
- не создавать открытый relay, не использовать внешнюю доставку;
- вести аудит администраторских действий и регулярно обновлять образы.

Не направляйте публичные домены реальных организаций на учебную платформу.
